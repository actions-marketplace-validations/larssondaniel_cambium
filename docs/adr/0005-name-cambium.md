# The project is named Cambium

The cambium is the thin layer in a tree where each new growth ring forms. The action reports exactly that layer: what grew between the base schema and the head schema. The name pairs with Canopy, the author's GraphQL client, without implying a hierarchy. Graft was rejected as a hard collision (an existing Marketplace action in CI diffing and a well-known unrelated project), Treering because a yearbook company owns the trademark and the GitHub org, and Understory because it names a layer below the canopy. The Marketplace listing is "Cambium: GraphQL schema diff" because the single word, like nearly every short English word, is already a GitHub user or org name, which the Marketplace forbids.
